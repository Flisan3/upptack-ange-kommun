Om projektet:

Det här en en webbsida där du kan utforska aktiviteter, evenemang och matupplevelser inom Ånge kommun. Webbsidan är tydlig och enkel att använda. Den är uppdelad i sidorna "Hem", "Aktiviteter", "Mat", "Evenemang", "Karta" och "Kontakt.
Projektet kombinerar html, css och javascript för att skapa ett trevligt verktyg för att upptäcka nya äventyr inom Ånge och närliggande orter. Webbsidans mest komplexa och främsta funktion är kartan som är länkad till alla aktiviteter.

Byggd med hjälp av:

[Leaflet](https://leafletjs.com)


[Pexels]((https://www.pexels.com/sv-se/))


[Font Awesome](https://fontawesome.com)

1. Ladda ned visual studio code på: [Visual studio code](https://code.visualstudio.com)
